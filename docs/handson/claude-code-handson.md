# Claude Code 超入門ハンズオン：Web-GIS アプリを作ろう

Claude Code に指示を出しながら、**地図の上に点・線・ポリゴンを描いて保存できる Web-GIS アプリ**を作ります。
コードを一から自分で書く必要はありません。「何を作りたいか」を伝え、出てきたものを **動かして確かめる** のがこのハンズオンの練習ポイントです。

> 前提
> - [README](../../README.md) の手順で、テンプレートから自分の `codespaces-env` リポジトリと Codespace を作り、Claude Code の認証（`CLAUDE_CODE_OAUTH_TOKEN`）まで済ませてある
> - Git の基本操作（branch / add / commit / push）は [git-handson.md](./git-handson.md) で一通り試してある
>
> Claude のプランによっては、途中で利用上限に達することがあります。その場合は、表示される時刻まで待ってから続きを進めてください（「困ったとき」の「前回の続きをしたい」を参照）。


## 完成イメージ

```
+------------------------------------------------------------------+
| +--------------------+                              +----------+ |
| | (1)                |                              | (2)      | |
| | ------------------ |                              | -------- | |
| | polygon  3f2a9c1b  |                              | [point]  | |
| | line     8d01e7aa  |                              | [line]   | |
| | point    c45b2f90  |                              | [polygon]| |
| |                    |           (3) MAP            | [select] | |
| | [export] [import]  |                              | [split]  | |
| | [clear all]        |                              | [union]  | |
| +--------------------+                              | [delete] | |
|                                                     | [undo]   | |
|                                                     +----------+ |
|                                                                  |
+------------------------------------------------------------------+
```

- **(1) サイドパネル**（地図の左側に重ねて表示）：描いた図形の「種類」と「ID の先頭8文字」の一覧、[書き出す] [読み込む] [すべて削除] ボタン
- **(2) ツールバー**（地図の右上）：点・線・ポリゴン・選択・分割・結合・削除・元に戻す
- **(3) 地図**（MapLibre、全画面）：ここに図形を描く

完成したアプリでできること：

- 東京駅周辺の地図を表示する
- 点・線・ポリゴンを描ける、選択して編集・削除・分割・結合できる
- 描いた図形が一覧に出る。行をクリックするとその図形に地図が移動する
- 図形を GeoJSON ファイルとして書き出し・読み込みできる
- ページを再読み込みしても図形が消えない


## 使う技術

| 技術 | 役割 |
| --- | --- |
| [Next.js](https://nextjs.org/) | React ベースの Web アプリの土台。画面やページを作る |
| [Tailwind CSS](https://tailwindcss.com/) | `class="p-4 bg-white"` のようにクラス名を書くだけで見た目を整える |
| [MapLibre GL JS](https://maplibre.org/) | ブラウザに地図を表示するライブラリ |
| [@sindicum/libre-draw](https://sindicum.github.io/libre-draw/) | MapLibre の地図上に点・線・ポリゴンを描いて編集するライブラリ |
| GeoJSON | 地図上の図形を表す JSON 形式のデータ。GIS で広く使われる |

> 💡 動作確認したバージョン：Next.js 16.4 / Tailwind CSS 4.3 / MapLibre GL JS 6.14 / @sindicum/libre-draw 0.17
> これより新しいバージョンでは、画面や設定の書き方が変わっていることがあります。うまく動かないときは、エラーをそのまま Claude Code に伝えましょう。

### ⚠️ つまずきポイント（地図が出ないとき）

うまく表示されないときは、**症状をそのまま Claude Code に伝える** のが一番の近道です。
ブラウザで開発者ツールを開き（Windows は `F12`、Mac は `Command + Option + I`）、「Console」タブを開いて、赤いエラーをコピーして貼り付けます。

```
地図が表示されない。ブラウザのコンソールに次のエラーが出ている:
（エラーをここに貼る）
```

よくある原因は次のとおりです。

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 画面が真っ白、エラーなし | 地図を入れる箱（div）の高さが 0 | 親要素に `h-screen` などで高さを付ける |
| `window is not defined` | サーバー側で地図ライブラリを動かそうとしている | ファイル先頭に `"use client"` を付け、地図の作成は `useEffect` の中で行う |
| `Worker` や `setWorkerUrl` 関連のエラー | MapLibre v6 は、地図の計算をする worker ファイルの場所を最初に教える必要がある | 下のコード例を参照 |

MapLibre v6 の worker 設定は、Next.js では次の書き方で動きます（動作確認済み）。

```tsx
import * as maplibregl from "maplibre-gl";

maplibregl.setWorkerUrl(
  new URL("maplibre-gl/dist/maplibre-gl-worker.mjs", import.meta.url).toString(),
);
```

### 📝 ここで理解しておくこと

```
@webgis-app/src/components/MapView.tsx を1行ずつ解説して。useRef と useEffect が何のためにあるのか、return で map.remove() している理由も教えて
```

ポイントは3つです。

- `"use client"`：このコンポーネントはブラウザで動く、という宣言。地図はブラウザでしか動かない
- `useEffect`：画面が表示された **あと** に地図を作る
- `return () => map.remove()`：画面から消えるときに地図を片付ける（開発中は React が表示 → 片付け → 再表示を1回わざと行うので、これがないと地図が二重にできる）

- 「すべて削除」→ 確認 → 消える → 再読み込みしても消えたまま

```

```


push してプルリクエストを作れば完成です。

```
プッシュしてプルリクエストを作って
```

> 💡 Claude Code は GitHub CLI（`gh`）を使ってプルリクエストを作ります。作られたら、表示された URL を開いて、取り込み先（base）が自分のリポジトリの `main` になっていることを確かめましょう。

> ⚠️ このハンズオンは **練習用** です。プルリクエストは **マージせずに閉じて** ください（`main` に `webgis-app/` を残さないため）。
> 閉じたあとは、次の順で片付けます。
>
> 1. ブラウザに保存した図形を消す：アプリの「すべて削除」ボタンか、開発者ツールの Application → Local Storage から消す
> 2. 開発サーバーを止める：`pnpm dev` を動かしているターミナルで `Ctrl + C`
> 3. ブランチと残ったファイルを消す（`node_modules/` や `.next/` はブランチを切り替えても残るため、`webgis-app/` ごと消す）
>
> ```bash
> git switch main
> rm -rf webgis-app
> git branch -D handson/webgis-自分の名前
> git push origin --delete handson/webgis-自分の名前
> ```

## Claude Code と開発するときのコツ

- **計画は PLAN.md に書き出し**、実装はその計画に沿って頼む。計画を変えるときは先に PLAN.md を直す
- **1ステップ＝1機能** で頼む。動いたらコミット。壊れても1つ前に戻れる
- **動作確認は自分の目で**。「できました」と言われても、ブラウザで触ってから次に進む
- うまくいかないときは **症状・エラーメッセージ・期待する動き** をそのまま伝える
- **「なぜそう書いたの？」と聞く**。理由を聞くと、自分の知識になる
- 会話が長くなって話がずれてきたら `/clear` で仕切り直す（コードは消えない）
- 新しいライブラリは **ドキュメントや型定義を読ませてから** 書かせる
- 秘密情報（API キーやトークン）は **プロンプトに貼らない**

## 困ったとき

| 状況 | やること |
| --- | --- |
| Claude Code が見当違いの作業を始めた | `Esc` で止めて、指示を言い直す |
| 変更をなかったことにしたい（コミット前） | `Esc` を2回（または `/rewind`）で、指示を出す前の状態に会話とコードを巻き戻す（※コマンドで作ったファイルは戻らない）。または `元に戻して` と頼む |
| 何が変わったか分からない | `!git diff` を見る、`今回の変更を説明して` と聞く |
| ポート 3000 が開けない | VS Code 下部の「ポート」タブを確認。`pnpm dev` が動いているかターミナルを見る |
| 前回の続きをしたい | `claude --continue` で起動、または起動後に `/resume` |
